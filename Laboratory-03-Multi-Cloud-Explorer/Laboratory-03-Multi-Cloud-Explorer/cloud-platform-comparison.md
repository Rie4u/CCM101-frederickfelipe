## Analysis Questions

1. **Which cloud provider offers the broadest range of services?**
   AWS offers the most extensive and mature selection of services across compute, serverless, and enterprise database categories.

2. **Which provider best integrates with Microsoft technologies?**
   Microsoft Azure provides direct, native compatibility with Windows Server, Active Directory, Office 365, and SQL Server.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
   Google Cloud Platform leads in container management and AI workflows because Google created Kubernetes and offers custom TPU hardware with Vertex AI.

4. **Which cloud platform would you personally choose and why?**
   I would choose AWS for its industry-standard usage, extensive developer resources, and deep documentation across all service domains.
