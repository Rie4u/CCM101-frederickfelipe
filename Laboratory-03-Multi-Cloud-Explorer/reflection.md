# Mission Reflection

1. **Which cloud platform impressed you the most?**
   AWS impressed me the most due to its extensive ecosystem, mature global infrastructure, and clear service breakdown, making it straightforward to understand foundational cloud computing principles.

2. **What similarities exist among AWS, Azure, and GCP?**
   All three providers offer core virtualized cloud primitives, including elastic compute instances, scalable object storage, private virtual network isolation, and identity/access management (IAM) controls.

3. **How do business requirements influence cloud platform selection?**
   Business requirements determine cloud selection based on existing enterprise dependencies (such as Microsoft Office 365 or Active Directory), specialized hardware needs (like TPUs for AI training), compliance standards, and overall budget constraints.

4. **What did you learn from acting as a Cloud Solutions Consultant?**
   I learned that cloud architecture requires evaluating multi-variable trade-offs to recommend options tailored to specific client workloads rather than relying on a single cloud provider for every use case.

5. **How has your GitHub Cloud Computing Portfolio improved after completing this mission?**
   Adding structured markdown comparisons, research sheets, and clear project documentation significantly improved the technical depth, organization, and visual quality of my GitHub repository portfolio.
