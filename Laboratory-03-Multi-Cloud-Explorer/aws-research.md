# Amazon Web Services (AWS) Research Documentation

## Brief Overview
Amazon Web Services (AWS) is a comprehensive, evolving cloud computing platform provided by Amazon. Launched in 2006, it offers over 200 fully featured services from data centers globally, serving millions of customers from fast-growing startups to enterprise businesses.

## Global Infrastructure
- **Regions:** 33+ geographic regions
- **Availability Zones:** 105+ Availability Zones
- **Edge Network:** 600+ CloudFront Points of Presence (POPs) and edge locations

## Cloud Management Console
The AWS Management Console provides a web-based UI for managing all AWS resources. It features customizable dashboards, quick service search, unified billing management, and integrates directly with AWS CloudShell and AWS CLI.

## Four (4) Core Services
1. **Compute Service:** Amazon EC2 (Elastic Compute Cloud) — Provides scalable virtual servers in the cloud.
2. **Storage Service:** Amazon S3 (Simple Storage Service) — High-durability object storage for backups and static assets.
3. **Networking Service:** Amazon VPC (Virtual Private Cloud) — Isolated virtual network environment for AWS resources.
4. **Identity & Security Service:** AWS IAM (Identity and Access Management) — Fine-grained access control for AWS resources and users.

## Three (3) Advantages
1. **Market Maturity:** Broadest and deepest set of features and services.
2. **Global Reach:** Massive global network ensuring high availability and low latency.
3. **Extensive Ecosystem:** Huge community support, third-party integrations, and learning resources.

## Typical Enterprise Use Cases
- Large-scale web application hosting and global CDN delivery.
- Enterprise data warehousing and big data analytics pipelines.
