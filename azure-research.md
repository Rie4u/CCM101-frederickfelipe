# Microsoft Azure Research Documentation

## Brief Overview
Microsoft Azure is a cloud computing platform launched by Microsoft in 2010. It provides a wide range of cloud services, including compute, analytics, storage, and networking, with seamless integration into Microsoft enterprise ecosystems.

## Global Infrastructure
- **Regions:** 60+ geographic regions worldwide
- **Availability Zones:** 3+ Availability Zones per supported region
- **Edge Network:** Extensive global edge network and ExpressRoute locations

## Cloud Management Console
The Azure Portal features an intuitive, customizable dashboard interface based on blades. It allows real-time resource tracking, built-in Cloud Shell support (Bash and PowerShell), and seamless management of hybrid setups.

## Four (4) Core Services
1. **Compute Service:** Azure Virtual Machines — On-demand scalable virtual computing capacity.
2. **Storage Service:** Azure Blob Storage — Massively scalable object storage for unstructured data.
3. **Networking Service:** Azure Virtual Network (VNet) — Secure private network representation in Azure.
4. **Identity & Security Service:** Microsoft Entra ID (formerly Azure AD) — Cloud-based identity and access management.

## Three (3) Advantages
1. **Seamless Microsoft Integration:** Perfect compatibility with Windows Server, Active Directory, and Office 365.
2. **Hybrid Cloud Support:** Industry-leading hybrid cloud tools like Azure Arc.
3. **Enterprise Cost Savings:** Flexible hybrid benefit pricing for existing Microsoft software licenses.

## Typical Enterprise Use Cases
- Hybrid cloud migration for existing enterprise Windows infrastructure.
- Enterprise identity synchronization and productivity app hosting.
